# Test Case ID

TC-CPOS-014

---

## Módulo

CandyStore (Backoffice)

---

## Categoría

Functional

---

## Nombre del Caso

Mostrar todos los productos disponibles.

---

## Objetivo

Verificar que el catálogo muestre todos los productos de confitería disponibles en la sucursal seleccionada.

---

## Precondiciones

- Cliente identificado.
- Sucursal seleccionada con inventario cargado.

---

## Datos de prueba

Sucursal con productos: Sambil Barquisimeto.

---

## Pasos

1. Identificar un cliente.
2. Observar el catálogo de productos en la sección de confitería.
3. Seleccionar la categoría "Todos".
4. Contar los productos visibles.

---

## Resultado esperado

Se muestran todos los productos disponibles para la sucursal. Cada producto muestra nombre, precio, categoría e imagen.

---

## Resultado obtenido

Verificado en pruebas anteriores. Funcionalidad correcta.
