## Nombre del Caso

Mostrar precio correctamente.

---

## Objetivo

Verificar que cada producto muestre su precio correcto según la configuración del sistema.

---

## Precondiciones

- Cliente identificado.
- Productos con precio registrado.

---

## Datos de prueba

Refresco Mediano — precio del backend.

---

## Pasos

1. Identificar un cliente.
2. Observar el precio mostrado de cada producto.
3. Comparar con el precio registrado en el backend (GET /concessions/products/available).

---

## Resultado esperado

El precio mostrado en la UI coincide con el registrado en la base de datos.
