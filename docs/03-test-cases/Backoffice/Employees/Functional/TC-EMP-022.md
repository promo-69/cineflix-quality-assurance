# Test Case ID

TC-EMP-022

---

## Módulo

Employees (Backoffice)

---

## Categoría

Functional

---

## Nombre del Caso

Visualizar listado de empleados.

---

## Objetivo

Verificar que el módulo de empleados muestre correctamente el listado de empleados registrados con sus datos.

---

## Precondiciones

- Usuario autenticado con permisos de empleados.
- Al menos un empleado registrado (admin).

---

## Datos de prueba

N/A

---

## Pasos

1. Acceder a `/admin/personal`.
2. Seleccionar la pestaña "Empleados".
3. Observar el listado.

---

## Resultado esperado

Se muestra una tabla con los empleados, incluyendo columnas como Nombre, Documento, Cargo y Sucursal.

---

## Resultado obtenido

El listado de empleados se muestra correctamente con columnas: Nombre, Documento, Cargo, Sucursal. El admin aparece en la lista.
