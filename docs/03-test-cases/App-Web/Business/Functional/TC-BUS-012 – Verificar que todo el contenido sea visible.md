# TC-BUS-012 – Verificar que todo el contenido sea visible

## Test Case ID

TC-BUS-012

---

## Módulo

Business

---

## Categoría

- Functional

---

## Nombre del Caso

Verificar que todo el contenido sea visible

---

## Objetivo

Verificar que en la pestaña "Marketing Empresarial" todo el contenido sea visible sin necesidad de scroll adicional, incluyendo el título, el párrafo descriptivo y el bloque de contacto corporativo.

---

## Precondiciones

- Navegador web actualizado.
- Conexión a internet disponible.
- URL /business accesible.

---

## Datos de prueba

- Ruta: /business
- Tab: Marketing Empresarial
- Dispositivo: Desktop (1920x1080)

---

## Pasos

1. Abrir el navegador y navegar a /business.
2. Hacer clic en la pestaña "Marketing Empresarial".
3. Verificar que el título "Alianzas y Publicidad" sea visible sin hacer scroll.
4. Verificar que el párrafo sobre pautas comerciales sea visible.
5. Verificar que el bloque "Contacto Corporativo" con marketing@cineflix.com sea visible.
6. Verificar que no existan elementos ocultos debajo del contenedor visible.

---

## Resultado esperado

Todo el contenido de "Marketing Empresarial" es visible en la pantalla sin necesidad de desplazamiento. El título, el párrafo descriptivo y el bloque de contacto se muestran completamente dentro del área visible del contenedor de tabs.
