# TC-BUS-014 – Verificar la correcta visualización de imágenes asociadas

## Test Case ID

TC-BUS-014

---

## Módulo

Business

---

## Categoría

- Functional

---

## Nombre del Caso

Verificar la correcta visualización de imágenes asociadas

---

## Objetivo

Verificar que si existen imágenes o elementos visuales asociados al apartado "Marketing Empresarial", estos se rendericen correctamente. En caso de no haber imágenes específicas, verificar que el layout se mantenga sin errores visuales por la ausencia de assets.

---

## Precondiciones

- Navegador web actualizado.
- Conexión a internet disponible.
- URL /business accesible.

---

## Datos de prueba

- Ruta: /business
- Tab: Marketing Empresarial
- Verificar si hay imágenes en el contenido de marketing

---

## Pasos

1. Abrir el navegador y navegar a /business.
2. Hacer clic en la pestaña "Marketing Empresarial".
3. Revisar si el apartado contiene imágenes o ilustraciones.
4. Si existen imágenes, verificar que carguen correctamente sin errores.
5. Si no existen imágenes, verificar que el layout se mantenga correcto sin espacios vacíos por imágenes faltantes.
6. Verificar que el bloque de contacto con fondo semitransparente (#7B1A82/20) se muestre correctamente.

---

## Resultado esperado

Si el apartado "Marketing Empresarial" contiene imágenes, estas se cargan correctamente. Si no contiene imágenes, el layout se mantiene limpio sin espacios vacíos o placeholders visibles. El bloque de contacto se renderiza con su fondo semitransparente correcto.
