# Cineflix Quality Assurance

## Descripción

Cineflix es una plataforma omnicanal para la administración y operación de una cadena de cines.

Este repositorio contiene toda la documentación relacionada con el proceso de Aseguramiento de la Calidad (QA) aplicado durante el desarrollo del sistema.

## Objetivos del Repositorio
- Centralizar la documentación QA.
- Gestionar casos de prueba.
- Gestionar defectos.
- Mantener trazabilidad.
- Documentar la estrategia de calidad.

---

## Alcance

Los esfuerzos de verificación seran en torno a la robustez de la arquitectura, la seguridad de la información y la experiencia del usuario en las diversas plataformas, garantizando que cada entrega aporte un incremento de software estable, alineado con los objetivos estratégicos del proyecto y libre de regresiones críticas.
