## Severidad (¿Cuánto afecta al sistema?)
Es una evaluación técnica realizada por el equipo de control de calidad (QA) o los desarrolladores. Define cómo el bug rompe la funcionalidad del software, sin importar si el sistema es muy usado o no.

Crítica/Bloqueante: El sistema falla por completo o una función vital es inutilizable y no hay solución alternativa.
Alta (Major): Una función importante no funciona como se espera, pero el resto del sistema sigue operando.
Media (Minor): Un fallo menor o una característica secundaria que no funciona bien, pero que no impide usar el programa.
Baja (Trivial): Un problema estético, errores tipográficos o detalles visuales que no afectan la funcionalidad.
